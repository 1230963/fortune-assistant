# 🏮 每日运势 · 桌面算命小助手

一个悬浮在 macOS 桌面上的每日运势小挂件：**原生 Swift + WKWebView**，无任何第三方依赖，
不联网，所有内容本地生成。同一天内运势固定（按日期播种），点「再求一签」可重新求签。

![icon](icon_1024.png)

## 功能

- 📜 **每日签文**：上上签 / 上吉 / 中吉 / 小吉 / 平签 五档，共 30 条签诗
- ⭐ **星级运势**：综合 / 爱情 / 事业 / 财运
- ✅❌ **今日宜忌**：接地气版（宜喝奶茶、忌深夜emo……）
- ☯️ **五行分析**（中国传统）：
  - 当日干支、日主五行、六十甲子纳音（如「辛卯日 · 松柏木」）
  - 五行能量分布条（年干/年支/日干/日支/纳音各计一票）
  - 日元强弱 → 推出**喜用五行**，幸运色与吉利方位都由喜用五行推导
  - **冲煞提示**（如「冲鸡（酉）」）；若正好冲你的生肖会红色加粗警告
- 🧧 **生辰八字命盘**（输入公历出生年月日 + 时辰，每日运势由此推算）：
  - **公历自动换算农历**（内置 1900-2049 农历数据表，含闰月，
    已与专业历法库逐日交叉验证），显示如「农历 庚午年五月廿三 午时」
  - 排四柱成表：**年柱以立春为界、月柱按节气（近似日期）、日柱精确推排、
    时柱按十二时辰**；每个天干地支标注五行与十神（日主居中），时辰选「未知」按三柱六字看
  - 日主（命主）五行与性格断语（如「辛金命 · 珠玉之质」）
  - **五行数量统计**（逐项着色）+ **五行分析**：最旺一行的性格描述、
    缺失五行的补缺建议；日主强弱（含月令得地加权）、**喜用神**及日常补运建议
  - **今日 × 命盘**：按十神（印星护身 / 食伤吐秀 / 财星当令 / 官星压身 / 比劫帮身）
    解读今日五行与你的日主关系；今日五行生合你的喜用神时会特别提醒
- 📊 **每日推断（真正的个性化）**：不再千人一面——结合你的四柱日主与今日干支的
  **十神关系**、日支刑冲合害、今日五行对你喜用神的扶抑，算出
  **综合 / 爱情 / 事业 / 财运四项 0-100 分**和吉凶判定（大吉→大凶），
  同一日子，不同人看到的结果完全不同
- ♈ **西方星座分析**：火/土/风/水四象、综合/爱情/事业三条每日指数、专属断语
- 🔀 **东西结合**：星座四象映射五行（风象属木之气），再看今日五行对你是
  「得生 / 同频 / 我克 / 我生 / 受压」哪一种关系，给出结合断语
- 💡 **每日小贴士**
- 🗓️ 标题栏显示公历 + 星期 + 干支年生肖 + 干支日（如「丙午马年 · 辛卯日」）
- 🌅 跨天自动刷新；拖动标题栏移动，位置自动记忆
- 🔮 **可收成悬浮小球**：点标题栏「−」按钮，面板缩成一颗「吉」字小球，
  球底圆点颜色即今日签级（金=上上签 橙=上吉 绿=中吉 蓝=小吉 灰=平签）；
  小球可拖动，**单击展开**回面板，右键有菜单；小球/面板状态退出后也会记住
- 🔒 **命盘隐私模式**：生辰八字、农历、四柱表等个人信息**默认隐藏**，
  点「点击查看」才展开，点「点击隐藏」再收起；**隐藏状态会记住，重启后保持**
- 🪟 **Windows 版**：同一份 index.html + 生辰八字引擎，
  用 Electron 打包成 Windows x64 绿色版（解压即用，无需安装）
- 🚀 开机自动启动（右键菜单里可开关）
- 单实例运行，重复打开不会叠罗汉

## 安装与文件位置

| 位置 | 说明 |
|---|---|
| `~/Applications/每日运势.app` | macOS 已安装的 APP（588K，原生二进制） |
| `~/Desktop/每日运势` | macOS 桌面快捷方式（别名） |
| `~/Desktop/每日运势.zip` | macOS 分发包（471K） |
| `~/Desktop/每日运势-Windows.zip` | **Windows x64 分发包（110M，含 Electron 运行时）** |
| `~/Library/LaunchAgents/com.zcode.fortune-assistant.plist` | 开机自启项 |
| `~/.fortune_assistant.json` | 配置（窗口位置） |
| `~/.fortune_assistant.pid` | 单实例锁（运行时才存在） |

> 分享给别人：对方解压后首次打开需 **右键 → 打开**（APP 未做苹果开发者签名）。
> 仅支持 Apple Silicon（arm64）Mac，macOS 13+。

### Windows 版使用说明

1. 解压 `每日运势-Windows.zip` 到任意目录（如 `C:\Apps\每日运势`）
2. 双击 `每日运势.exe` 即可运行（绿色软件，无需安装）
3. 功能与 macOS 版完全一致：
   - 无边框悬浮窗（`-webkit-app-region: drag` 拖动）
   - 首次启动弹出生辰输入面板
   - 点标题栏「−」收成小球（双击展开）
   - 点标题栏「✕」关闭
   - 右键菜单：再求一签 / 我的星座与八字 / 开机自动启动 / 关闭
4. 开机自启通过 Windows 注册表 `Run` 键实现（`app.setLoginItemSettings`）

> Windows 版未做代码签名，SmartScreen 可能提示「未知发布者」，
> 点「更多信息」→「仍要运行」即可。仅支持 Windows 10/11 x64。

## 操作说明

- **移动**：按住顶部红色标题栏拖动；小球状态下按住小球拖动
- **收成小球**：点标题栏「−」；**展开**：单击小球（或右键 → 展开运势面板）
- **再求一签**：点金色按钮，或右键菜单（同一天的默认签不变）
- **设置星座 / 生辰八字**：点右下角按钮或右键菜单 →「我的星座与八字」。
  出生时间按**公历**输入；时辰不知道可以选「未知」（按三柱六字排）。
  说明：年柱以立春为界（命理惯例），生肖显示以春节为界（民间惯例）；
  月柱节气用近似日期（±1~2 天误差），仅作娱乐参考
- **关闭**：点标题栏 ✕，或右键菜单「关闭每日运势」；明天开机又会自动出现
- **彻底退出自启**：右键菜单 → 取消勾选「开机自动启动」

## 卸载

```bash
launchctl bootout gui/$(id -u)/com.zcode.fortune-assistant 2>/dev/null
rm -f ~/Library/LaunchAgents/com.zcode.fortune-assistant.plist
rm -rf ~/Applications/每日运势.app ~/Desktop/每日运势 ~/Desktop/每日运势.zip
rm -f ~/.fortune_assistant.json ~/.fortune_assistant.pid
```

## 源码与重新构建

```
fortune.py          终端版/原型：python3 fortune.py --print 打印今日运势
main.swift          原生 APP 源码（窗口、标题栏、自启、JS 桥）
index.html          挂件界面与全部运势逻辑（HTML/CSS/JS）
build_icon.py       用 Pillow 绘制图标（朱砂红 + 金字「吉」）并生成 icns
snapshot_tool.swift 离屏渲染截图工具（无屏幕录制权限时的视觉自检）
build_app.sh        一键构建：生成图标 → 编译 → 打包 → ad-hoc 签名 → build/每日运势.app
```

重新构建并安装：

```bash
./build_app.sh
rm -rf ~/Applications/每日运势.app
cp -R build/每日运势.app ~/Applications/
```

## 备注

本机系统自带的 Python/Tk 因命令行工具（CLT）版本新于系统而损坏
（`macOS 15 (1507) or later required, have instead 15 (1506)`），
任何 tkinter 窗口程序都无法运行——所以成品改为纯原生 Swift 实现，
不依赖 Python，也不受该问题影响。`fortune.py` 保留为终端版使用。
